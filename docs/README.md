# Local Image Generator — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first image.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Download the built-in model and generate your first image. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "Model not downloaded", "Server unreachable", "No ComfyUI at this address", "Not a workflow". |

The [README](https://github.com/johannes-kaindl/local-image-generator/blob/main/README.md) covers what the plugin does, how to install it, every setting and the API for other plugins.
